Exercice 3 - Conversion implicite et explicite :
Les conversions consistent à traduire des type de données en autres types de données
Elles peuvent être implicites (passer de moins "fort" mathématique à plus "fort") ou explicites (lorsque le type d'origine est plus fort que le type de destination)

int a = 15;
double b = a; 

ici, on cherche à convertir un int en réel (devient 15.0)

int a = 15;
double b = a; implicite, compile, car un int peut être traduit en double

double c = 9.8;
int d = c; explicite, ne compile pas, car 9.8 ne peut pas être un entier

double e = 9.8;
int f = (int) e; explicite, compile car (int) e va rendre une troncature de 9.8, soit 9

long g = 100;
int h = g; explicite, ne compile pas, car 100 est enregistré comme long, type trop grand pour être contenu dans un int (même si 100 peut être un int)
